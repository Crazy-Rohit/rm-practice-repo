# Contributing

Stage 5 of the Git Learning Portal uses this repository.

1. Fork it to your account.
2. Add one new file, `contributors/<your-username>.md`.
3. Put one short line in that file.
4. Open a pull request into `Crazy-Rohit/rm-practice-repo`.

A workflow merges the pull request when that is the only change. It reads the file list through the GitHub API and does not run the pull request's code.
